# 教程:从其他端移植"过场动画 + 配音"到 WotLK 客户端

> 目标:给地精弄一个真正的科赞开场动画 + 配音
> 难度:⭐⭐⭐⭐(比改SQL难很多,要折腾文件和工具)

---

## 第一部分:先搞懂原理(不懂会白忙)

### WotLK 开场动画的完整链条

```
ChrRaces.dbc (动画ID 121)
  → CinematicSequences.dbc (摄像机ID 182)
    → CinematicCamera.dbc (两样东西:)
       ├─ 画面: Cameras\FlyByTroll.mdx   ← 运镜+场景(决定"飞过什么风景")
       └─ 声音: voiceID 4080
            → SoundEntries.dbc → TrollNarration.mp3 (旁白配音)
                                 + 字幕文本(客户端本地化)
```

**三个能换的零件:**
| 零件 | 文件 | 难度 |
|------|------|------|
| 画面(运镜+场景) | `Cameras\XXX.mdx` | ⭐⭐⭐⭐⭐ 最难,跨版本几乎不通用 |
| 配音(旁白声音) | `Sound\CinematicVoices\XXX.mp3` | ⭐⭐ 较易,换个mp3即可 |
| 字幕(屏幕文字) | 客户端本地化文件 | ⭐⭐⭐ 中等 |

## 第二部分:关键现实——两个"坑"先告诉你

### 坑1:画面(.mdx)跨版本几乎不能直接用
- WotLK 用 **`.mdx`/`.m2`** 格式的运镜文件
- 大灾变(4.x)的科赞动画用了**新版 .m2 格式 + .ogv 视频**,WotLK 引擎读不了
- 强行放进去 → 崩溃或黑屏
- **结论:科赞的"画面"基本搬不过来。我们只能借 WotLK 已有的运镜(比如巨魔海岛 FlyByTroll)**

### 坑2:配音格式
- WotLK 旁白是 **`.mp3`**(单声道/立体声都行)
- 大灾变配音也是 mp3/ogg。**mp3 可以直接用,ogg 要转成 mp3**

### 所以最现实的方案(强烈推荐)
> **画面 = 借 WotLK 巨魔海岛运镜(已做好,动画ID=121)**
> **配音 = 换成你找到的/自己做的 mp3,命名成 TrollNarration.mp3 覆盖**
> **字幕 = 用游戏内NPC对白替代(我们已经做了)**

这样观众看到:海岛风光(巨魔运镜)+ 你的配音 + 进游戏后NPC讲科赞故事。

## 第三部分:操作步骤

### 路线A:只换配音(推荐,最容易出效果)

#### 你需要准备
- 一段配音 mp3(从大灾变端提取的科赞旁白,或自己用AI配音生成中文)
- 工具:**MPQEditor**(Ladik's MPQ Editor,免费)

#### 步骤

**1. 准备配音文件**
- 如果从其他端提取:用 MPQEditor 打开那个端的 MPQ,
  找 `Sound\` 下的科赞旁白文件,导出
- 如果是 `.ogg` 格式 → 用工具转成 `.mp3`(见下方"格式转换")
- 把你的配音**改名成** `TrollNarration.mp3`
  (因为我们的地精动画借的是巨魔运镜,它念的就是这个文件)

**2. 放进客户端**
方法① 散装文件(最简单):
```
你的客户端\Data\Sound\CinematicVoices\TrollNarration.mp3
```
(没有这些文件夹就自己建)

方法② 塞进 patch MPQ:
- MPQEditor 打开 `Data\patch-?.MPQ`
- 把 mp3 拖进去,路径填 `Sound\CinematicVoices\TrollNarration.mp3`

**3. 测试**:新建地精,看动画时听配音变了没

> ⚠️ 副作用:巨魔玩家的开场动画配音也会跟着变(因为共用同一个文件)。
> 如果不想影响巨魔,要走"路线B:新建独立动画ID",见下。

---

### 路线B:给地精建独立动画ID(不影响其他种族,进阶)

如果你想让地精用**完全独立**的动画+配音,不蹭巨魔的,要新建一套DBC记录:

**1. SoundEntries.dbc 新增一条**(比如 voiceID=50001)
   - 指向你的新配音文件 `GoblinKezanNarration.mp3`

**2. CinematicCamera.dbc 新增一条**(比如摄像机ID=50001)
   - 画面仍指向 `Cameras\FlyByTroll.mdx`(借巨魔的画面)
   - voiceID 填 50001(你的新配音)

**3. CinematicSequences.dbc 新增一条**(比如动画ID=50001)
   - 指向摄像机 50001

**4. ChrRaces.dbc** 把地精动画ID改成 50001

**5. 这4个改过的DBC + 新mp3,全部塞进客户端 + 服务器**

> 这样地精播自己的配音,巨魔不受影响。
> 缺点:要改4个DBC,且客户端服务器都要同步,容易出错。
> 我可以帮你生成这套DBC(你只要提供mp3)。

## 第四部分:音频/视频格式转换

### 工具:ffmpeg(命令行,免费万能)

**ogg/ogv/wav → mp3**:
```bash
ffmpeg -i 输入.ogg -codec:a libmp3lame -qscale:a 2 TrollNarration.mp3
```

**从大灾变的 .ogv 视频里只提取声音 → mp3**:
```bash
ffmpeg -i 科赞动画.ogv -vn -codec:a libmp3lame -qscale:a 2 TrollNarration.mp3
```
(`-vn` = 去掉视频,只要音频)

**控制时长/音量**(WotLK巨魔旁白约30秒,你的配音最好接近):
```bash
ffmpeg -i 输入.mp3 -t 30 -af "volume=1.0" TrollNarration.mp3
```

### AI生成中文配音(没有现成配音时)
- 用任何 TTS(文字转语音)工具,输入你写的科赞旁白文字
- 导出 mp3 → 改名 TrollNarration.mp3 → 按路线A放进客户端

## 第五部分:如果你执意要画面也是科赞的(不推荐)

跨版本移植 .mdx 运镜 + 场景模型,需要:
1. 从大灾变提取科赞动画的 .m2 摄像机文件 + 引用的所有场景模型/贴图
2. 用 **M2 转换工具**(如 M2Mod / WoW Model Editor)把 Cata 的 .m2 降级转成 WotLK 的 .m2/.mdx
3. 场景里引用的地图/模型 WotLK 没有的,还要一起搬
4. 极易失败、易崩溃,投入产出比极低

**老实建议:画面就用巨魔海岛,够像科赞了。把精力放在配音和NPC剧情上。**
