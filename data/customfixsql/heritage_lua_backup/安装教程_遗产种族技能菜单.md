# 遗产种族技能菜单 (Heritage Horizons) 安装教程

玩家自选种族技能的 AIO 菜单功能。本教程说明在一台新服务器上如何完整安装。

## 一、前置要求

1. 服务器装了 **mod-ale**（ALE，Eluna兼容的Lua引擎）或 mod-eluna
2. 服务器 `lua_scripts/AIO_Server/` 目录里有 **AIO.lua**（Rochet2的AIO框架）
3. 客户端装了 **AIO_Client** 插件（放在 WoW客户端 `Interface/AddOns/AIO_Client/`）
   - 客户端插件文件来源：客户端 `Interface/AddOns/AIO_Client/`

## 二、安装步骤

### 1. 拷贝 Lua 脚本

把这3个文件放到服务器的 `lua_scripts/AIO_Server/` 目录：
```
racialServer.lua   ← 服务端逻辑(本备份目录里有)
racialClient.lua   ← 客户端UI(本备份目录里有,AIO会自动推送给客户端)
```

### 2. 修改 AIO.lua（★关键，否则点击无反应）

ALE 会重复加载脚本，导致 AIO 注册冲突。必须改 `lua_scripts/AIO_Server/AIO.lua`：

找到 `AIO.RegisterEvent` 函数，**删掉这一行**：
```lua
assert(not AIO_BLOCKHANDLES[name], "an event is already registered for the name: "..name)
```
改成直接覆盖（保留下一行 `AIO_BLOCKHANDLES[name] = func`）。

**不改这个，整个菜单点击都没反应（不学技能不扣钱）。**

### 3. 导入数据库

执行 SQL 文件 `20260604_heritage_racial_menu.sql`（acore_world库）：
- 创建遗产菜单NPC 98888 Vorthelas
- 创建召唤大胖生物 36613 + 模型

另外在 **acore_characters 库** 手动建表：
```sql
CREATE TABLE IF NOT EXISTS `player_swapped_racial` (
  `guid` int unsigned NOT NULL,
  `race_id` int unsigned NOT NULL,
  PRIMARY KEY (`guid`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci;
```

### 4. 重启服务器

ALE 会自动加载 racial 脚本。启动日志若没有 `already registered: RACIAL_SERVER` 报错，说明第2步改对了。

## 三、使用方法

玩家进游戏后，三种方式打开菜单：
1. **登录自动弹出**（新角色/每次登录）
2. **斜杠命令** `/rc` 或 `/racialchange`
3. **屏幕图标按钮**（小地图旁，可拖动）—— racialClient.lua里 `isWorldIconOn = true` 开启
4. **找NPC 98888** 对话

## 四、技能崩溃/失效的修复套路

菜单有133个各种族技能，部分在WotLK核心会崩/无效，根因都是缺配套数据：

| 现象 | 根因 | 修复 |
|------|------|------|
| 点技能崩溃 | 召唤的生物不存在 | 补 creature_template 生物 |
| 召唤物模型错 | 缺 creature_model_info | 补模型碰撞数据 |
| 大灾变机制崩(坐骑类) | 核心不支持 | 换实现或放弃 |

配套数据来源：`newRaceSources/DB_FULL/`

## 五、金币规则（正常设计，非bug）

- ≤11级：免费选/改技能
- \>11级：每次改技能扣 1 金（10000铜）

修改：racialServer.lua 里 `costToActivate` 和 `GetLevel() > 11` 判断。
